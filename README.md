# 🧮 Calculadora (Clase 14 MATH)
Este proyecto consiste en una calculadora desarrollada en Java, pensada para resolver operaciones comunes dentro de una carpintería. Fue realizada como parte de la práctica de Programación Orientada a Objetos.

## 📌 Funcionalidades
La aplicación incluye los siguientes cálculos:

## 🔢 Redondeo de números
Permite redondear cantidades (por ejemplo, metros de madera necesarios para un pedido).

### ⚪ Cálculo de área de una mesa circular
Calcula el área a partir del diámetro ingresado por el usuario.
- Fórmula utilizada: `π * radio²`

### ⬛ Cálculo de lado de mesa cuadrada
Dado el área total, calcula cuánto mide cada lado de la mesa.
- Fórmula: `lado = √área`

### 🎲 Juego: Adivinar número
Genera un número y el usuario debe adivinarlo:
- Si acierta → obtiene un **15% de descuento**
- Si no → se muestra el número correcto

## 🛠️ Tecnologías utilizadas

- Java
- IntelliJ IDEA
- Clase `Math` (para cálculos matemáticos)
